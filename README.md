# Code Art Wall — PyCon AU 2026

Every piece written in Python at the Aquion booth, and the code that drew it.

**This directory is the published site.** It is served by GitHub Pages from
`main` at the repository root, at <https://pycon26.adeptask.com>, and it is
hand-edited from here on.

That domain used to serve the wall itself, so `404.html` catches the links
attendees saved: `/piece/20` opens the gallery on piece 20, and any other
path opens the gallery. `CNAME` is what maps the domain to this repository;
deleting it sends the site back to its github.io address.

It was first generated by `python -m artwall.gallery` in
[pycon-2026-art-wall](https://github.com/tpgionfriddo/pycon-2026-art-wall),
with:

```
--first 34,1,2 --winners 28,56,66 --exclude 83,100,75
```

Re-running that generator would **overwrite `index.html` and undo every
change made here**. If the pieces themselves ever need to change, regenerate
into a scratch directory and port the display changes across deliberately.

## What is here

- `index.html` — the whole gallery: grid, focused view, and every piece's
  source, highlighted at build time and parked in inert `<template>` elements
- `media/` — one `.webm` or `.png` per piece, plus a `.poster.jpg` still for
  each animated one. A tile shows its still and borrows a video only while it
  is on screen
- `.nojekyll` — stops Pages running Jekyll over the site

## Removing a piece

Delete its media and rebuild nothing: `rm media/14.*` takes the loop and its
still together, the tile hides itself when its image does not load, and the
grid closes up behind it.
